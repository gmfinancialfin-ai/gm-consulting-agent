Privacidad del asistente

El chat solicita tu consentimiento antes de enviar mensajes para recibir respuestas de IA. Al activarse la conexión, tus consultas y el historial reciente se envían al servidor de GM y a OpenAI para generar una respuesta. Evita compartir contraseñas, documentos de identidad, datos financieros o información confidencial.

El historial se mantiene temporalmente en la memoria del navegador. Puedes borrarlo con «Borrar conversación» o al recargar. El servidor no registra el contenido del chat y solicita a la API que no almacene la respuesta para su recuperación; esto no significa retención cero por parte del proveedor.

Para controlar el uso, el servidor utiliza un contador temporal asociado a un hash de la dirección IP en Redis. El contador vence en 120 segundos. No contiene mensajes.

Al elegir «Hablar con el equipo», se abre WhatsApp con tus consultas para que revises el texto y decidas enviarlo. No se envía automáticamente. WhatsApp aplica sus propias condiciones de tratamiento de datos.

Las respuestas pueden contener errores. El asistente no confirma citas, cotizaciones ni contratos. Para consultas sobre el uso de tus datos, contacta a GM Consulting Group en somosgm.ai@gmail.com.
